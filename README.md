# Ikigai

Website for Ikigai, a UGC (User Generated Content) agency.

## Overview

Ikigai helps brands create user-generated content, connect with creators, and manage social video campaigns.

## Features

- **Services**: UGC strategy, content creation, and creator sourcing.
- **Booking**: Direct scheduling via Calendly.
- **Responsive**: Designed for mobile, tablet, and desktop.

## Local Setup

To run the site locally:

```bash
python3 -m http.server 8000
```

Open `http://localhost:8000` in your browser.
